# GenshinSimulatedWish

一个纯前端实现的原神祈愿模拟器（抽卡模拟），使用 HTML5 + jQuery + CSS 动画搭建，无需后端，浏览器打开即玩。

在线体验：[https://xueqian17654.github.io/GenshinSimulatedWish](https://xueqian17654.github.io/GenshinSimulatedWish)

## 功能简介

- **祈愿模拟**：单抽 / 十连，还原原神的抽卡流程与表现
- **概率机制**：还原 5 星 / 4 星基础概率、保底机制、命定值（定轨）机制
  - 5 星基础概率 0.6%，随垫数递增，90 抽保底
  - 4 星基础概率 5.1%，10 抽保底 4 星及以上
  - 定轨（命定值）：歪了积累命定值，命定值为 1 时下次 5 星必为定轨物品
  - 捕获明光机制
- **定轨系统**：选择定轨物品，支持同类型限定、仅歪常驻（可切换）等规则
- **抽卡动画**：单人展示动画、十连全员展示动画、星级特效、出场语音
- **历史记录**：本地保存抽卡历史，可查看详情
- **设置页**：隐藏定轨按钮、永远不歪、可歪不同类、仅歪常驻等开关
- **数据持久化**：原石、纠缠之缘、定轨状态、抽卡历史全部保存在浏览器 localStorage

## 技术栈

- 纯 HTML / CSS / JavaScript（jQuery）
- Web Animations API（元素动画）
- CSS 变量 + JS 动态控制
- 数据全部来自静态 JSON（`static/char.js`、`static/weap.js`、`static/arti.js`）

## 目录结构

```
├── index.html          # 入口页面（即 wish.html）
└── static/             # 全部静态资源
    ├── char/           # 角色立绘 / 小立绘 / 出场语音(wav)
    ├── charicon/       # 角色头像
    ├── weap/           # 武器立绘
    ├── weapicon/       # 武器图标
    ├── arti/           # 圣遗物
    ├── elem/           # 元素图标
    ├── pict/           # UI 图片
    ├── audio/          # 音效
    └── 286932797/      # 抽卡动画视频(mp4)
```

## 素材来源

- 角色 / 武器 / 圣遗物图片数据：[Lunaris](https://api.lunaris.moe)（第三方原神数据 API）
- 语音、动画等媒体：游戏截取 / 录制
- 抽卡视频动画：自制
